# 🎵 AI Music Generator (Windows)

โปรแกรมสร้างเพลงอัตโนมัติ ทำงานออฟไลน์บน Windows

| ตัวเลือก | ค่าที่ใช้ |
|---|---|
| แพลตฟอร์ม | Windows 10/11 (รันด้วย Python หรือ build เป็น `.exe`) |
| การสร้างดนตรี | `audio_midi` – ได้ทั้งไฟล์เสียง `.wav` และไฟล์ `.mid` |
| เสียงร้อง | `preserve` – เสียงร้องของคุณ **ไม่ถูกแก้ไข** ดนตรีถูกสร้างให้เข้ากับเสียงร้อง |
| แนวเพลง | `all` – 16 แนว (**isan**, pop, rock, hiphop, edm, house, lofi, jazz, blues, rnb, country, reggae, latin, classical, ambient, metal) หรือสุ่มอัตโนมัติ |

> **หมายเหตุสำคัญ:** นี่คือ *ต้นแบบ (prototype)* ที่ใช้ทฤษฎีดนตรี + กฎของแต่ละแนว + ซินธ์ที่เขียนเอง
> ไม่ได้ใช้โมเดล AI สร้างเสียงสำเร็จรูป ผลลัพธ์เป็นเสียงสังเคราะห์พื้นฐาน เหมาะเป็นสเก็ตช์/แบ็คกิ้งแทร็ก/ไฟล์ MIDI
> เพื่อนำไปโหลดซาวด์ที่ดีกว่าใน DAW ต่อ ส่วนการต่อยอดไปโมเดล AI จริง ดูหัวข้อ [แผนต่อยอด](#-แผนต่อยอด)

## 🎋 แนว `isan` – อีสานอินดี้

เลือกแนว `isan` (ค่าเริ่มต้นในหน้าต่างโปรแกรม) จะได้วงที่มีเครื่องดนตรีดังนี้

| เครื่อง | บทบาท |
|---|---|
| **พิณ** | ดีดซ้ำลายสั้น ๆ บนบันไดเสียงเพนทาโทนิก มีโน้ตกรอและสไลด์ |
| **แคน** | เสียงลมค้าง (โน้ตราก + ห้า) ตลอดเพลง และตีสับจังหวะในท่อนฮุก |
| **โหวด** | เสียงขลุ่ยหายใจ เล่นวลีสั้น ๆ ตอบรับเสียงร้อง เฉพาะช่วงที่ไม่มีคนร้อง |
| **โปงลาง** | ไม้ตีสั้น ๆ วนซ้ำในท่อนร้องและท่อนฮุก |
| **กีตาร์ / เปียโน** | กีตาร์อาร์เปจโจ (ท่อนร้อง) และสตรัม (ท่อนฮุก), เปียโนคอร์ดเปิดกว้างพร้อมโน้ตแทรกเล็กน้อย |
| **ซินธ์** | แพดรองพื้นด้านล่าง |
| **กลอง / เบส** | กลองอินดี้จังหวะกลาง ๆ + เบสเล่นตามราก |
| **เครื่องเคาะ** | ฉิ่ง (จังหวะเสี้ยว), กลองคองก้า, ไข่เขย่า |

**ทำให้เข้ากับเสียงร้องได้อย่างไร** (เมื่อใส่ `--vocal`)
1. **จังหวะ** – ตรวจ BPM ละเอียดระดับทศนิยม และหาว่า "ห้องแรก" ตกที่วินาทีไหน แล้วเลื่อนดนตรีให้ตรงกับเสียงร้อง
   (เสียงร้องไม่ต้องเริ่มตรงต้นไฟล์)
2. **คีย์** – ตรวจคีย์ของเสียงร้อง แล้วใช้เฉพาะโน้ตบันไดเสียงเพนทาโทนิกของคีย์นั้น
3. **คอร์ดรายห้อง** – วิเคราะห์ว่าแต่ละห้องคนร้องโน้ตอะไรบ้าง แล้วเลือกคอร์ดที่รองรับโน้ตเหล่านั้นมากที่สุด
4. **เว้นช่องให้เสียงร้อง** – พิณ/โหวด/โปงลาง/เปียโนแทรกเล่นเฉพาะช่วงที่คนร้องเงียบ (ตอบโต้ แบบ call-and-response)
   ส่วนแคน/กีตาร์/ซินธ์/เครื่องเคาะยังเล่นต่อแต่ลดความดังลง
5. เสียงร้องต้นฉบับยังคงไม่ถูกแก้ไข (ดนตรีลดเสียงลงเล็กน้อยตอนมีเสียงร้อง)

```bat
run_cli.bat -g isan --vocal "C:\Users\me\Music\my_vocal.wav" -o output -n isan_song
run_cli.bat -g isan --bars 48 --seed 7 --stems
```

> ข้อจำกัด: เสียงเครื่องดนตรีเป็นเสียงสังเคราะห์ที่จำลองลักษณะของพิณ แคน โหวด ไม่ใช่การบันทึกเสียงจริง
> ทำนองของเครื่องเล่นแทรกสร้างจากบันไดเสียง ไม่ได้ลอกทำนองเสียงร้อง ถ้าอยากได้เสียงจริงให้นำไฟล์ `.mid` (แยกแทร็กแล้ว)
> ไปใส่ซาวด์พิณ/แคน/โหวดของจริงใน DAW

## ⚙️ ทำงานอย่างไร

```
(เสียงร้อง wav/mp3/flac)
   │  pitch.py: ตามระดับเสียง (YIN) ─► แตกเป็นโน้ตที่ร้องจริง (แยกพยางค์ซ้ำด้วย)
   ▼
vocal.py ─► คีย์ (จากโน้ตที่ร้อง) · BPM (จากจังหวะเริ่มโน้ต) · จุดตกห้อง · แผนที่ทำนองต่อ 1/8 · ความดังรายห้อง
   ▼
composer.py ─► คอร์ดรายห้อง (Viterbi ให้ตรงกับโน้ตที่ร้อง) → เครื่องดนตรีทุกชิ้น
   ▼
synth.py + instruments.py ─► เสียง (เล่นเหลื่อมแบบคนจริง) ─► fx.py: ตัวเครื่อง · ห้อง · คอมเพรส ─► ดนตรีสเตอริโอ
   ▼
mixer.py ◄── เสียงร้องต้นฉบับ (ไม่แก้ไข) ─► song.wav + song_accompaniment.wav + song.mid
```

### ดนตรีเข้ากับเสียงร้องอย่างไร
| สิ่งที่ปรับให้ | วิธีทำ |
|---|---|
| **คีย์** | นับโน้ตที่ร้องจริงถ่วงด้วยความยาว/ความดัง และให้น้ำหนักโน้ตท้ายวลี (ไม่ใช้สเปกตรัมเดา) |
| **จังหวะ (BPM)** | หาจากตำแหน่งเริ่มโน้ต ละเอียด 0.05 BPM และแก้ปัญหาเลือกเร็ว/ช้าเป็นสองเท่า |
| **จุดตกห้อง** | เลื่อนดนตรีให้จังหวะหนักตรงกับต้นวลี/โน้ตยาว ปรับเองได้ด้วย `--shift-ms` (หรือช่อง Shift ในโปรแกรม) |
| **คอร์ด** | เลือกทีละห้องด้วย Viterbi ให้โน้ตที่ร้องเป็นเสียงคอร์ดมากที่สุด (ทดสอบเสียงจำลอง: จาก ~50% เป็น ~80%) |
| **ช่องว่าง** | พิน โหวด โปงลาง เล่นเฉพาะตอนเสียงร้องเงียบ และ **เลียนทำนองท่อนที่เพิ่งร้องจบ** (call & response) |
| **ไดนามิก** | ร้องแรงดนตรีเข้มขึ้น ร้องเบาดนตรีเบาลง |
| **ย่านเสียง** | คอร์ดกีตาร์/เปียโน/ซินธ์ถูกวางต่ำกว่าระดับเสียงร้อง ไม่ทับกัน; เบสเรียบง่ายลงตอนมีเสียงร้อง |

**ถ้ายังรู้สึกว่าไม่เข้า:** กดปุ่ม **Analyse vocal** ดูค่า BPM/คีย์ที่ตรวจได้พร้อมความมั่นใจ
- ความมั่นใจของ BPM ต่ำ → พิมพ์ BPM จริงของเพลงลงช่อง BPM (`--bpm`)
- จังหวะเลื่อนไปครึ่งจังหวะ → ใส่ค่า Shift เป็น ± ครึ่งจังหวะ (เช่น BPM 96 ครึ่งจังหวะ = 312 ms)
- คีย์ผิด (เช่น ได้ C major แต่ร้อง A minor ซึ่งใช้โน้ตชุดเดียวกัน) → เลือก Key/Scale เอง
- ใช้ไฟล์เสียงร้องเปล่า (acapella) ที่ไม่มีดนตรีหรือเสียงสะท้อนมาก จะแม่นที่สุด

### ความสมจริงของเสียง
- สายดีด (พิน กีตาร์ เบส) จำลองการสั่นของสายจริง (Karplus-Strong), เปียโนมี 3 สายต่อโน้ตจูนเหลื่อมนิดหน่อย,
  แคนมีลมหายใจและเสียงกก, โหวดมีวิบราโตและลมผ่านท่อ, กลองหลายชั้น
- เล่นเหลื่อมแบบคนจริง: เวลาและความแรงของแต่ละโน้ตไม่ตรงเป๊ะ โน้ตซ้ำใช้เสียงคนละแบบ (round-robin)
- มีห้องสะท้อนเสียง ตัวเครื่อง (ไม้กีตาร์/กล่องพิน) และคอมเพรสเซอร์รวมวง
- **ข้อจำกัดที่ต้องรู้:** ทั้งหมดเป็นเสียงสังเคราะห์ ไม่ได้ใช้ตัวอย่างเสียงอัดจากเครื่องจริง จึงไม่เทียบเท่าวงจริง
  ถ้าต้องการสมจริงสูงสุด ให้นำไฟล์ `.mid` ที่ได้ไปเล่นกับ sample library / VST ของพิน แคน โหวด ใน DAW

## 🖥 Standalone (ไม่ต้องติดตั้ง Python)

Build จาก GitHub แล้วจะได้ 2 ไฟล์ zip (ดู "ขั้นที่ 4" ด้านล่าง):

| ไฟล์ | คืออะไร | เหมาะกับ |
|---|---|---|
| `AIMusicGenerator-windows.zip` | `AIMusicGenerator.exe` ไฟล์เดียว + `AIMusicGenerator-cli.exe` | แจกง่าย ดับเบิลคลิกใช้ได้เลย (เปิดครั้งแรกช้า 5–10 วินาที) |
| `AIMusicGenerator-portable.zip` | โฟลเดอร์พกพา (แตกแล้วรันได้ทุกที่ / USB) | เปิดเร็วกว่า ไม่ต้องแตกไฟล์ชั่วคราวทุกครั้ง |

- รวมตัวอ่านไฟล์เสียงไว้ในตัวแล้ว: รองรับเสียงร้อง **wav / mp3 / flac / ogg** โดยไม่ต้องลง ffmpeg
- จำการตั้งค่าล่าสุดไว้ให้ (`%LOCALAPPDATA%\AIMusicGenerator\settings.json`) ไม่เขียนอะไรลงรีจิสทรี ลบโฟลเดอร์ทิ้งก็เหมือนถอนการติดตั้ง
- ถ้าโปรแกรมพัง จะมีหน้าต่างแจ้งและบันทึกรายละเอียดที่ `%LOCALAPPDATA%\AIMusicGenerator\error.log`
- ถ้า Windows SmartScreen เตือน → **More info → Run anyway** (ไฟล์ยังไม่ได้ลงนามดิจิทัล) และบางโปรแกรมแอนตี้ไวรัสอาจแจ้งเตือนเกินจริงกับไฟล์ที่ build ด้วย PyInstaller

## 🚀 วิธีรันบน Windows (ไม่ผ่าน GitHub)

1. ติดตั้ง **Python 3.10 ขึ้นไป** จาก https://www.python.org/downloads/ (ตอนติดตั้งติ๊ก **Add python.exe to PATH**)
2. ดาวน์โหลดโปรเจกต์ (ปุ่ม **Code → Download ZIP**) แล้วแตกไฟล์
3. ดับเบิลคลิก `setup_windows.bat` (ทำครั้งเดียว)
4. ดับเบิลคลิก `run_gui.bat` → เปิดหน้าต่างโปรแกรม
5. เลือกแนวเพลง (`all` = สุ่ม) → เลือกโหมด (Audio + MIDI) → (ถ้ามี) เลือกไฟล์เสียงร้อง → กด **Generate**
6. ไฟล์จะอยู่ที่โฟลเดอร์ `Music\AIMusicGenerator` (ปุ่ม **Open folder**)

### แบบคำสั่ง (CLI)

```bat
:: สร้างเพลงสุ่มแนว ได้ทั้ง .wav และ .mid
run_cli.bat

:: เลือกแนว ความยาว และ seed (seed เดิม = เพลงเดิม)
run_cli.bat -g lofi --bars 32 --seed 123 -o output -n my_song

:: คงเสียงร้องเดิม + สร้างดนตรีรอบเสียงร้อง (ดึง BPM/คีย์จากเสียงร้องอัตโนมัติ)
run_cli.bat --vocal "C:\Users\me\Music\my_vocal.wav" -g pop -o output -n with_vocal

:: ได้เฉพาะ MIDI / เฉพาะเสียง / แยกสเต็ม
run_cli.bat -g jazz --mode midi
run_cli.bat -g edm --mode audio --stems --bits 24
```

| ตัวเลือก | ความหมาย |
|---|---|
| `-g, --genre` | `all` หรือชื่อแนว (`--list-genres` เพื่อดูทั้งหมด) |
| `--mode` | `audio_midi` (ค่าเริ่มต้น) / `audio` / `midi` |
| `--vocal FILE` | ไฟล์เสียงร้องที่ต้องการคงไว้ |
| `--bars N` | ความยาวเป็นห้อง (ค่าเริ่มต้น 32) |
| `--bpm`, `--key`, `--scale` | กำหนดเอง (ไม่ใส่ = สุ่มตามแนว / ตามเสียงร้อง) |
| `--seed N` | ใช้ซ้ำเพื่อได้เพลงเดิม |
| `--lead on/off` | เมโลดี้ลีดที่โปรแกรมสร้าง (ปิดอัตโนมัติเมื่อมีเสียงร้อง) |
| `--duck DB` | ลดเสียงดนตรีตอนมีเสียงร้อง (ค่าเริ่มต้น 4 dB, 0 = ปิด) |
| `--vocal-gain DB` | ปรับความดังเสียงร้อง (0 = ไม่แตะ) |
| `--stems` | ส่งออกไฟล์แยกเครื่องดนตรี |
| `--bits 16/24` | ความละเอียด WAV |

ไฟล์ที่ได้: `song.mid`, `song.wav`, `song_accompaniment.wav`, `song_info.json` (และ `song_stem_*.wav`)

## 🐙 วิธีนำขึ้น GitHub และ build .exe (แบบละเอียด)

> **ถ้า Actions ขึ้นกากบาทแดง ❌ ให้ทำตามหัวข้อนี้ตั้งแต่ต้น** สาเหตุที่พบบ่อยที่สุดคือใน repo มีแค่ไฟล์ `build-windows.yml`
> แต่ไม่มีซอร์สโค้ด (`run_app.py`, โฟลเดอร์ `src`) ทำให้ build ไม่มีอะไรให้ทำ ต้องอัปโหลดโปรเจกต์ **ทั้งโฟลเดอร์**

### ขั้นที่ 1 – เตรียมไฟล์
1. แตกไฟล์ `ai-music-generator.zip` ลงเครื่อง (คลิกขวา → Extract All)
2. เปิดโฟลเดอร์ `ai-music-generator` ต้องเห็น `run_app.py`, `README.md`, โฟลเดอร์ `src`, `tests`, `tools`, `.github` ในระดับเดียวกัน

### ขั้นที่ 2 – อัปโหลดขึ้น Repository (เลือกทางใดทางหนึ่ง)

**ทางที่ 1: ใช้สคริปต์ (ง่ายสุด ถ้าติดตั้ง Git แล้ว)**
1. ติดตั้ง Git for Windows จาก https://git-scm.com/download/win (กด Next ไปเรื่อย ๆ)
2. เปิด PowerShell หรือ Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วรัน (เปลี่ยน URL เป็น repo ของคุณ):
   ```bat
   push_to_github.bat https://github.com/ชื่อผู้ใช้/ชื่อrepo.git
   ```
3. ครั้งแรก Git จะเปิดหน้าต่างให้ล็อกอิน GitHub ให้ล็อกอินให้เสร็จ
4. สคริปต์ใช้ `--force` จึงเขียนทับไฟล์ที่เคยสร้างผ่านเว็บ (เช่น `build-windows.yml` ตัวเก่า)

**ทางที่ 2: อัปโหลดผ่านหน้าเว็บ (ไม่ต้องลง Git)**
1. เข้า repo → ปุ่ม **Add file → Upload files**
2. เปิดโฟลเดอร์ `ai-music-generator` ใน File Explorer → กด **Ctrl+A** เลือกทุกอย่างข้างใน
   (ต้องรวมโฟลเดอร์ `.github`, `src`, `tests`) แล้ว **ลากทั้งหมดไปวางบนหน้าเว็บ**
3. รอจนอัปโหลดครบ แล้วกด **Commit changes**
4. เช็กหน้า **Code** ของ repo ว่าเห็น `run_app.py`, `src`, `tests`, `tools`, `.github` ครบ
   ถ้ามีไฟล์ `build-windows.yml` เดิมอยู่แล้ว การอัปโหลดจะเขียนทับให้เอง
5. ถ้าโฟลเดอร์ย่อยไม่ขึ้น (เว็บบางครั้งไม่รับโฟลเดอร์ซ้อนจำนวนมาก) ให้ใช้ทางที่ 1 แทน

### ขั้นที่ 3 – รัน Build .exe
- หลังอัปโหลดเสร็จ workflow **Build Windows Standalone** จะรันเองอัตโนมัติ
- หรือสั่งเอง: แท็บ **Actions** → เลือก **Build Windows Standalone** ทางซ้าย → **Run workflow** → **Run workflow**
- รอประมาณ 3–6 นาที จนเห็นเครื่องหมายถูกสีเขียว ✅

### ขั้นที่ 4 – ดาวน์โหลดโปรแกรม
1. คลิกชื่อรอบที่รัน (แถวบนสุด)
2. เลื่อนลงล่างสุดหัวข้อ **Artifacts** → คลิก **AIMusicGenerator-windows** จะได้ zip 2 ไฟล์ (ตัวเดี่ยว และแบบพกพา)
3. แตก zip จะได้
   - `AIMusicGenerator.exe` – หน้าต่างโปรแกรม ดับเบิลคลิกใช้ได้เลย
   - `AIMusicGenerator-cli.exe` – แบบคำสั่ง เช่น `AIMusicGenerator-cli.exe -g rock --bars 16`

> Windows SmartScreen อาจเตือน "Windows protected your PC" เพราะไฟล์ไม่ได้ลงนามดิจิทัล → กด **More info → Run anyway**

### ถ้ายังขึ้น ❌ แดง ทำอย่างไร
1. คลิกที่รอบที่ล้มเหลว → คลิกงาน **build** ทางซ้าย
2. หาขั้นตอนที่มีกากบาทแดง กดขยายอ่านบรรทัดสุดท้ายของข้อความ error
3. ตารางสาเหตุที่พบบ่อย

| ข้อความ / ขั้นตอนที่ล้ม | สาเหตุ | วิธีแก้ |
|---|---|---|
| **Check project files are present** → "Project files are missing" | ยังไม่ได้อัปโหลดซอร์สโค้ด | ทำขั้นที่ 2 ให้ครบ |
| `Workflow does not exist` / ไม่มีแท็บ Run workflow | ไฟล์ workflow ไม่อยู่ที่ `.github/workflows/` | ตรวจชื่อโฟลเดอร์ให้ตรง ต้องมีจุดนำหน้า `.github` |
| **Smoke test the CLI exe** ล้ม | โปรแกรมรันไม่ผ่านบน Windows | คัดลอก error มาให้ผมแก้ต่อ |
| Run tests ขึ้นเตือนเหลือง ⚠️ | เทสต์ไม่ผ่านแต่ build ต่อได้ | ใช้ exe ได้ แต่ส่ง log มาให้ตรวจ |
| Release ไม่ขึ้น | ต้องสร้างแท็ก `v*` | ดูขั้นต่อไป |

### (ไม่บังคับ) ออก Release ให้คนอื่นดาวน์โหลด
```bash
git tag v0.1.0
git push origin v0.1.0
```
workflow จะแนบ `AIMusicGenerator-windows.zip` ไว้ในหน้า **Releases** ให้อัตโนมัติ

ดับเบิลคลิก `build_exe.bat` → ได้ไฟล์ในโฟลเดอร์ `dist`

```bat

```

เทสต์ครอบคลุม: ทุกแนวสร้างเพลงได้, seed เดิมได้เพลงเดิม, MIDI เขียน/อ่านกลับตรงกัน, ไฟล์เสียงออกถูกต้อง,
และ **เสียงร้องถูกคงไว้จริง** (วัดจากการเทียบมิกซ์กับไฟล์เสียงร้องต้นฉบับ)

## 🛠 แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| `python` is not recognized | ติดตั้ง Python ใหม่แล้วติ๊ก *Add to PATH* หรือใช้ `py -m venv .venv` |
| GUI ไม่เปิด / ไม่มี tkinter | ติดตั้ง Python จาก python.org (ตัวติดตั้งมี tkinter มาให้ ต้องไม่ถอดติ๊ก *tcl/tk*) |
| อ่านไฟล์ mp3 ไม่ได้ | `pip install soundfile` หรือติดตั้ง ffmpeg หรือแปลงเป็น WAV ก่อน |
| ดนตรีไม่เข้ากับเสียงร้อง | กำหนด `--bpm` / `--key` / `--scale` เองให้ตรงกับเพลง |
| exe โดน antivirus บล็อก | พบบ่อยกับ PyInstaller ให้ใช้วิธีรันด้วย Python แทน หรือ build เองบนเครื่อง |

## 🔭 แผนต่อยอด

- ใช้โมเดล AI จริงสร้างเสียง: **MusicGen / Stable Audio** (ต้องมี GPU + PyTorch) แทนซินธ์ในโมดูล `synth.py`
- ใส่ตัวอย่างเสียงจริงของพิณ/แคน/โหวด (sample) แทนซินธ์ในโมดูล `synth.py`
- แยกเสียงร้องจากเพลงเต็มด้วย **Demucs** ก่อนเข้าโหมด preserve
- เมโลดี้จากเสียงร้อง: ใช้ **basic-pitch / CREPE** ถอดโน้ตแล้วสร้างคอร์ดให้ตรงกับทำนอง
- โหลด SoundFont (`.sf2`) ผ่าน **FluidSynth** เพื่อให้เสียงเครื่องดนตรีสมจริงขึ้น
- ปรับจังหวะเสียงร้องให้ตรงกริด (time-align / beat-sync) และส่งออกเป็น VST3 (โครงสร้างเดียวกับโปรเจกต์ JUCE)

## เสียงสมจริงขึ้นด้วย SoundFont (.sf2)

โปรแกรมสังเคราะห์เสียงเองได้ แต่ถ้าต้องการเสียงเครื่องดนตรีจริง ให้ใส่ไฟล์ `.sf2` (เช่น GeneralUser GS, FluidR3) ลงในโฟลเดอร์ `soundfonts/` ข้าง ๆ โปรแกรม

- GUI: ช่อง SoundFont = `auto` (ใช้ไฟล์แรกที่เจอ) / `none` (เสียงสังเคราะห์) / เลือกไฟล์เอง
- CLI: `--soundfont auto|none|path.sf2`
- แมปเสียง: พิณ=Banjo(105), แคน=Accordion(21), โหวด=Pan flute(75), กีตาร์=25, เปียโน=0, ซินธ์=89, โปงลาง=Xylophone(13), เบส=33, กลองผ่าน bank 128
- เครื่องดนตรีที่ฟอนต์ไม่มี จะกลับไปใช้เสียงสังเคราะห์ในตัว
- รองรับ SF2 พื้นฐาน (ลูป, ADSR, ช่วงคีย์/velocity) ยังไม่รองรับ modulator/filter/LFO/.sf3 และทดสอบกับฟอนต์สังเคราะห์เท่านั้น ยังไม่ได้ลองกับฟอนต์ GM จริง

## VST3 / Standalone plugin (ยังไม่ได้ทดสอบ)

โฟลเดอร์ `vst3/` เป็นโปรเจกต์ JUCE ที่เรียก `AIMusicGenerator-cli.exe` สร้างเพลง แล้วเล่นไฟล์เสียงตาม transport ของ DAW พร้อมส่ง MIDI ออก
1. GitHub → Actions → **Build VST3** → Run workflow (หรือ push tag `vst3-1`)
2. ดาวน์โหลด artifact `AIMusicGenerator-VST3` คัดลอกโฟลเดอร์ `.vst3` ไปที่ `C:\Program Files\Common Files\VST3`
3. ในปลั๊กอิน ใส่ path ของ `AIMusicGenerator-cli.exe` เลือกไฟล์เสียงร้อง แล้วกด Generate

ข้อควรรู้: โค้ดนี้เขียนโดยไม่ได้คอมไพล์จริง (ไม่มี JUCE/Windows ในเครื่องที่เขียน) อาจต้องแก้ error เล็กน้อยตอน build ครั้งแรก

## ทำไมยังไม่เท่า Suno

Suno ใช้โมเดลประสาทขนาดใหญ่บนคลาวด์ที่สร้างเสียงดนตรีโดยตรง โปรแกรมนี้ทำแบบนั้นไม่ได้ แต่ใช้การเรียบเรียงที่เขียนไว้ (riff ซ้ำ, เบสล็อกกับกลอง, คอร์ดตามเสียงร้อง) + เสียงสังเคราะห์/SoundFont ถ้าอยากได้เสียงจริงที่สุด ให้ใช้ `.mid` ที่ได้ไปใส่ปลั๊กอินเครื่องดนตรีใน DAW

## เครื่องมือแก้ไข/วิเคราะห์เสียง (เพิ่มใหม่)

```
python -m aimusicgen.tools_cli stretch in.wav out.wav --rate 1.2        # time stretch
python -m aimusicgen.tools_cli pitch   in.wav out.wav --semitones 2     # pitch shift
python -m aimusicgen.tools_cli convert in.wav out.flac --sr 48000 --bits 24   # WAV/FLAC/MP3, 44.1/48/96 kHz
python -m aimusicgen.tools_cli chords  song.wav                          # ตรวจคอร์ดจากเสียง
python -m aimusicgen.tools_cli mixdown song.aimproj mix.wav              # มิกซ์โปรเจกต์ (volume/pan/mute/solo)
python -m aimusicgen.tools_cli separate song.wav --out stems [--six]     # แยก stem ด้วย Demucs
```
- `src/aimusicgen/audio_tools.py`: stretch, pitch, fade, cut/copy/paste, replace section, chord detection, export
- `src/aimusicgen/project.py`: บันทึก/เปิดโปรเจกต์ `.aimproj`
- `separate` ต้อง `pip install demucs` (ดึง PyTorch) และดาวน์โหลดโมเดลครั้งแรก ได้ vocals/drums/bass/other (หรือเพิ่ม guitar/piano กับ `--six`) ไม่ใช่ 18 ชนิด และยังไม่ได้ทดสอบจริงในเครื่องที่เขียน
- ยังไม่มี: Text-to-Music, Vocal Generation, Cover/Remix ด้วยโมเดล AI, ตัวติดตั้ง Windows, GUI มัลติแทร็ก/Piano Roll
